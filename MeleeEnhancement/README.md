# Melee Enhancement
### A few tweaks to Zer0 and Krieg to enhance their melee gameplay.

# Changelog

### Melee Enhancement v2.0
- Ported to the new PythonSDK (v3.8), older SDK versions should keep using v1.0
- Uses the SDK's new built-in Structs, so the Structs mod is no longer required.
- Buzz Axe Bombadier regains its regular explosion, with an additional slag explosion that no longer slags himself.
